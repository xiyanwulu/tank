# 坦克大战 · Tank Battle

一个用 HTML5 Canvas 写的经典坦克大战，**单文件、零依赖、零构建**——把 `index.html` 双击打开就能玩。

没有外部图片、没有音频文件、没有 CDN、没有 npm。全部 480×480 的画面是 Canvas 手绘的，音效是 WebAudio 实时合成的。

## 在线试玩

👉 **https://xiyanwulu.github.io/tank/**

（本地直接打开 `index.html` 也可以，不需要起服务器。）

## 玩法

守住屏幕底部的老鹰基地。敌军从顶部三个出生点源源不断涌出，**基地被摧毁就立刻结束**——不管你还有几条命。

消灭当关全部敌军即过关，共三关。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `↓` `←` `→` | 移动 |
| `空格` / `J` | 开火 |
| `P` / `Esc` | 暂停 |
| `M` | 静音开关 |
| `Enter` | 开始 / 进入下一关 / 重开 |

手机上会自动显示屏幕方向键。

## 游戏要素

**地形**

| | 挡坦克 | 挡子弹 | 可摧毁 |
| --- | :-: | :-: | :-: |
| 🧱 砖墙 | ✅ | ✅ | ✅ |
| ⬜ 钢墙 | ✅ | ✅ | 只有「钢」道具生效后可以 |
| 🌊 河流 | ✅ | ❌ | — |
| 🌲 树丛 | ❌ | ❌ | 会盖住坦克，可以用来藏身 |
| 🦅 基地 | ✅ | ✅ | 被敌军打中就结束（自家炮弹无效） |

**敌军**

| 类型 | 速度 | 血量 | 特点 | 分数 |
| --- | :-: | :-: | --- | :-: |
| 普通 | 慢 | 1 | 灰白色，炮击间隔长 | 100 |
| 快速 | 快 | 1 | 青色，走位飘忽 | 200 |
| 炮手 | 中 | 2 | 绿色，**开火极快** | 300 |
| 重装 | 慢 | 3 | 红色，挨打会变色，越打越暗 | 400 |

**道具**（击毁敌军时约 22% 概率掉落，开过去即可拾取，14 秒后消失）

- **盾** — 8 秒无敌
- **命** — 生命 +1
- **速** — 速射，同时可打出 2 发
- **钢** — 破钢弹，可以打穿钢墙
- **爆** — 全屏秒杀当前所有敌军

## 和红白机原版的两处不同

原作里自己的炮弹也能打掉自家基地，而且基地只有一层砖——这里做了两处体验调整：

1. **自家炮弹打不坏基地。** 玩家出生点就在基地同一行，原版规则下随手向右一炮就自杀了，体验很差。
2. **基地护墙加厚到两层**（8 块砖）。原版中路几乎直通基地，敌军从正上方出生点几发炮弹就能拆家，来不及反应。

## 项目结构

```
.
├── index.html   # 全部内容：CSS + Canvas 渲染 + 游戏逻辑，约 1200 行
├── README.md
└── LICENSE
```

代码按这几块组织，都在 `index.html` 的 `<script>` 里：

| 区块 | 内容 |
| --- | --- |
| 常量 / 关卡地图 | 地块类型、出生点；地图用 `fill` / `sfill` 绘图原语生成并左右镜像，不手写字符画 |
| 音效 `Sfx` | WebAudio 振荡器 + 白噪声，无音频文件 |
| 输入 | 方向键栈（后按的方向优先），键盘与触屏共用一套状态 |
| `Tank` | 移动、贴边辅助、转向对齐；玩家输入与敌军 AI 分两条分支 |
| `Bullet` | 分步推进（每步 ≤4px）避免高速穿墙 |
| 渲染 | 全部 Canvas 手绘，含水面波纹、履带动画、爆炸粒子 |
| 主循环 | `requestAnimationFrame` + dt 钳制，固定逻辑不受帧率影响 |

关卡地图的写法值得一提——不用字符画，而是：

```js
sfill(m, 1, 1, 3, 2, T.BRICK);   // 在 (1,1) 画 3×2 的砖块，并自动左右镜像
```

`sfill` 会自动在右侧镜像一份。手写 15×15 的字符画非常容易数错列数，用绘图原语则不会。

## 本地开发

